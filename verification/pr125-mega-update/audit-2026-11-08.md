**Resultado desta rodada:** o snapshot de código auditado é o SHA exato `6ad15e8`; esta atualização ao PR é só documentação e metadados de evidência. O ZIP separado do GitHub Actions não foi baixado; isso não impediu a cópia dos assets já versionados. Não houve alteração de código/runtime, banco, preview ou produção.

## Métricas disponíveis e limites de interpretação

O relatório de evidência versionado publica uma comparação de bundle baseline/build local: JavaScript total raw de 7.341.649 B para 7.253.065 B (−88.584 B; −1,21%), gzip de 2.389.550 B para 2.366.894 B (−22.656 B; −0,95%) e Brotli Q6 de 2.254.273 B para 2.235.758 B (−18.515 B; −0,82%). Por rota, Match 3D cai 50.318 B raw; a Home cai 15.450 B raw; Nova Carreira cai 60.896 B raw. São números do relatório baseline/build local, não LCP, TBT, FPS, latência de rede nem prova isolada de causa. Para qualquer comparação nova, confira primeiro o arquivo do artefato `bundle-before-after` do SHA atual. [8] [11]

O run atual tem artefatos `lighthouse-results` (dois arquivos), `bundle-before-after`, `simulation-stress-results`, `match-setup-performance-results` e `graphics-benchmark-bundle`. O endpoint público lista seis artefatos e os vincula a `6ad15e8`; os dois Lighthouse somam cerca de 9,4 MB e o bundle de gráficos cerca de 3,0 MB. O pacote visual separado tem 52.334.565 bytes e o de lifecycle 402.909 bytes. Os artefatos consultados informam expiração em **22/11/2026**. [8] [9] [10]

A política Lighthouse atual no relatório usa score mínimo 0,90, TBT máximo 400 ms e LCP máximo 2.700 ms, com CLS ≤0,1, três execuções e agregação pessimista. A mudança histórica do piso 0,98→0,97 é real, mas não é mais a política descrita no head atual. O pass atual comprova os thresholds vigentes e não deve ser anunciado como melhoria de experiência sem olhar os resultados JSON no artefato. [4] [7] [11]

CodSpeed não falhou o gate de release, mas ficou neutral e reportou duas regressões de benchmark: MatchSim setup −3,2% e rig fallback geometry −2,53%. Esse sinal deve ser investigado separadamente de Lighthouse e do gate crítico, sem ser apagado pelo status verde do workflow. [14]
