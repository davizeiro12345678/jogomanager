## Como interpretar os números

Este relatório separa o que mudou no código local do que foi observado no Supabase de produção. O TTL e o conteúdo foram alterados no checkout local; nenhuma migração, configuração de Auth ou publicação foi feita nesta etapa. As métricas do banco são uma fotografia consultada em 18/10/2026, aproximadamente às 21:25 no horário de Brasília. Não existe uma fotografia anterior comparável para atribuir a essas alterações uma redução de custo ou latência em produção.
